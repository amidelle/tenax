# Tenax

Tenax holds a session on a machine you own and shows it in a native client.

This is the **public distribution repo** — release binaries and the public
issue tracker. The source tree is private.

## Install the agent (Linux)

```sh
curl -fsSL https://tenax.jackolab.com/install.sh | sh
sudo tenax service install   # systemd unit
tenax login                  # device code; host joins your account
```
